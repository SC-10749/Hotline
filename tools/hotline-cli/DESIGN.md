# Hotline 控制台设计

## 视觉主题
蓝白色开发者项目控制台。白色侧栏和卡片、浅蓝灰画布，品牌与主操作使用克制的蓝色。保留现有项目管理结构与交互。

## 色彩
画布 #f5f8fd，表面 #ffffff，分隔线 #dde5f1，主文字 #1f2d45，次文字 #5f6e85，主色 #2864dc，浅蓝 #edf3ff。成功为绿色、启动中为琥珀色、错误与停止为红色；颜色同时配合文字表达状态。

## 排版
西文优先 Aptos / Segoe UI；中文使用 PingFang SC、Microsoft YaHei、Noto Sans SC。正文 14px，行高 1.65。项目路径和日志使用等宽字体。品牌字样 28px，主标题 34px。

## 组件
按钮最小高度 40px，圆角 8px；卡片 12px；弹窗 16px。蓝色实心主按钮、描边 Readme 按钮、浅红停止按钮。已启动后才展示项目链接。

## 布局
桌面 232px 白色侧栏，内容区域内边距 40px；项目卡片采用自适应网格，避免单项目无限拉伸。左侧显示项目中心与六个未来能力菜单；未来菜单统一标记“规划”，点击只展示计划内容，不接入实际功能。不恢复项目分类菜单或应用内嵌方案，项目链接仍在新标签页打开。移动端品牌区转为顶部，菜单横向滚动，内容边距 20px。

## 层级
1px 边框建立结构，卡片使用低透明蓝灰阴影；弹窗使用较深遮罩。禁止光晕与渐变装饰。

## 行为约束
保留启动中、已启动、停止中、失败状态及 Readme 技术栈、功能、服务依赖、启动步骤；不自动跳转页面。链接始终由用户点击。

## 响应式
760px 以下侧栏转顶部；480px 以下工具栏纵向堆叠。长地址和说明换行，禁止页面横向溢出，弹窗内部可滚动。

## 动效
悬停与按压仅用 140–180ms 的颜色、边框和阴影过渡；键盘焦点使用蓝色轮廓。悬停位移仅对精确指针启用。减少动态效果偏好关闭过渡与位移。
