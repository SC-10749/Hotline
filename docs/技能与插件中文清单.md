# 技能与插件中文清单

本页是技能与插件的**中文显示名 + 一句话简介**对照表：英文目录名与 frontmatter `name` 保持不变（技能注册表按 `name` 校验和匹配，`catalog.validate` 只接受 1–64 位小写英文、数字与连字符），中文名只用于阅读与界面显示。

## 项目技能（`skills/`）

| 目录 | 中文名 | 简介 |
| --- | --- | --- |
| `hotline-tdd` | TDD 开发流程 | 把需求条目变成先失败的测试，再按 RED→GREEN 实现并跑交付检查。 |
| `requirement-analysis` | 需求分析与诊断 | 先把模糊需求问清楚，再产出可验收的 FR/NFR/SC、约束清单与 MoSCoW 范围边界。 |
| `interview-coach` | 面试教练 | 结构化备考、面经转写分析、模拟演练与故事库管理，覆盖产品、工程、设计、数据等岗位。 |
| `resume-writing` | 简历写作 | 按 GitHub 高星开源规范写或改简历，约束句式、量化、强动词与 ATS 格式。 |

## 官方插件

插件包带 sha256 树校验，改包内文件会让校验失效，因此插件包本身不改，中文名与简介只记在这里。

| 插件 | 中文名 | 简介 |
| --- | --- | --- |
| `academic-paper-assistant` | 学术论文助手 | 论文润色、摘要精炼、同行评审与 LaTeX 排版，不编造数据与引用。 |
| `repo-xray` | 仓库透视 | 从 Git 历史看代码地图、热点文件、高风险文件与知识流失。 |
| `rea` | 逆向分析 | 拆 APK、IPA 与桌面应用，追功能实现并复刻到自己的项目。 |
| `computer-use` | 桌面操作 | 用原生桌面能力查看应用、点击、输入并验证结果。 |
| `ppt` | 演示文稿 | 读写与分析 PPTX，可从零生成，也可按模板保留样式编辑。 |
| `senior-fullstack-developer` | 全栈开发 | 项目感知的前端、后端与全栈实现、验证与交付流程。 |
| `excel` | 电子表格 | 读写转换 Excel，处理公式、格式、图表与数据清洗。 |
| `browser-use` | 浏览器控制 | 复用当前会话内置浏览器的页面与登录态做网页操作。 |
| `video-creater` | 视频生成 | 用 H3、H3 Max、H2.3 文生视频、关键帧与多模态参考出片。 |
| `pdf` | PDF 处理 | 提取、生成、重排、OCR 与表单填写 PDF。 |
| `word` | Word 文档 | 创建、套模板、编辑、修复与比较 DOCX。 |
| `image-generation` | 图片生成 | 文生图与改图，支持 Logo、图标、3D/CG 与局部修改。 |
| `ponytail-mcode` | 马尾辫 | 极简资深工程师模式：最小可行实现、改动评审与全仓审计。 |
