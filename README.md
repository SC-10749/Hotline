# Hotline 插件实验室

探索最新热点技术的可实用性，并将经过验证的成果封装成开箱即用的 Skill 或 MCP。

## 目标

- 跟踪值得关注的新模型、新协议、新工具与新工作流。
- 用最小可行原型验证真实场景中的安装成本、稳定性、性能和维护成本。
- 将验证通过的能力整理为可复用、可配置、可独立运行的插件。

## 目录

- `mcp/`：MCP 服务、工具与资源。
- `skills/`：可复用的 Skill 定义、提示词和辅助脚本。
- `plugins/`：完整插件项目及其打包配置。

## 开发原则

1. 先验证可用性，再扩展功能。
2. 默认提供清晰的安装、配置和启动方式。
3. 示例配置只使用占位符；真实密钥和服务地址保留在本地。
4. 每个插件都应包含用途说明、依赖、运行方式和验证命令。

## 开始开发

在对应目录创建插件，并为其补充独立的 README、依赖清单和示例配置。完成后，确保插件可以在干净环境中按文档启动和验证。
